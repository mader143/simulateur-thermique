# Simulateur Thermique
# Équipe 5 (Da best)

## Description

Simulateur thermique 2D pour modéliser la diffusion de chaleur dans une plaque métallique. Le projet regroupe une simulation numérique en Python avec interface graphique PyQt5, du code Arduino pour l'acquisition et la régulation, et les données expérimentales pour la validation.

## Contenu du projet

**Simulation Python** : Résolution par différences finies de l'équation de diffusion thermique, interface utilisateur interactive, génération de résultats et animations.

**Code Arduino** : Contrôleur PID pour régulation thermique, conditionnement des signaux, identification expérimentale, enregistrement des données.

**Données expérimentales** : Caractérisation thermique en trois étapes avec phases de chauffage, refroidissement et conditions stables.

**Conception PCB** : Schémas et circuits imprimés KiCad avec Arduino Mega 2560, amplificateurs opérationnels, et conditionnement analogique.
